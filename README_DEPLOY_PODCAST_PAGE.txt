DEPLOYMENT NOTES

This package adds a new Podcast page to your personal brand website.

Upload/merge everything in this folder into the root of your GitHub repository. Keep these files and folders beside each other:

index.html
about.html
speaking.html
podcast.html
assets/
  hero-background.png
  podcast/podcast-cover.png
  speaking/...

The navigation has been updated on Home, About, Speaking, and Podcast to include the new Podcast link.

The Podcast page is intentionally lightweight. It does not auto-sync episodes. It links visitors to Spotify, Apple Podcasts, and the RSS feed.
